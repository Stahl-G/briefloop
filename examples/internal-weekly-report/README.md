# 企业内部周报示例

这是虚构团队的合成材料与示例报告，可用于了解 BriefLoop 的材料输入、报告编辑和 Word 导出。数据不描述真实公司。

- [合成来源材料](source.txt)
- [网页改稿后的示例报告](report.md)

## 不调用模型先看一次

在空工作区欢迎页点击“先看合成示例（无需模型）”。来源和稿件会实际保存，可查看来源、修改、刷新和生成 Word；示例标明合成、未评分，自动学习关闭，不会伪造审阅结果。它展示产品操作，不证明模型生成效果。

## 用模型自己生成一次

1. 启动 BriefLoop，新建一个工作区。
2. 上传 `source.txt`，选择通用模板和企业内部报告模式。
3. 读者填写“团队负责人”，时间填写“2026-09-01 至 2026-09-07”。
4. 目标字数设为 350，上限 500；仅使用本地来源。
5. 输入下面的目标，选择自己的运行时和模型后生成：

> 仅依据材料写一份内部周报，分为本周变化、影响、下一步三个小节，附本周与上周对比表。写清已安排的核对动作，保留准确日期和单位，简明引用材料。

生成后可以在网页修改，再点击生成 Word。示例不附评分或“验证通过”声明，报告仍需按实际用途核对。
