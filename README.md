# BriefLoop 0.17.0

一个基于 Codex CLI 的个人本地 Agent 工作台：围绕你的问题寻找来源、生成简报、独立评价，并把反馈整理成后续可用的经验。

本版界面与文档以中文为主。国际化和行业 Deep Research 留到后续版本。

## 快速开始

```sh
git clone https://github.com/Stahl-G/briefloop.git
cd briefloop
./start.sh
```

只需这一个仓库。首次启动自动创建 `.venv`、安装 Python 依赖和随仓库提供的 WikiSkill wheel、启动本地服务并打开网页；无需第二次 clone，也无需手动构建前端。

使用前需要：

- macOS，以及 Python 3.11 或更新版本。
- 已安装并完成认证的 Codex CLI；对话和任务执行需要它。
- 首次安装依赖需要网络。使用 Tavily 时另行配置自己的 Tavily Key。

也可指定目录和端口：

```sh
./start.sh --workspace /path/to/workspace --port 8765 --no-open
```

服务只监听本机。关闭网页不会停止正在执行的任务；从网页“停止”或关闭服务进程结束执行。

## 现在可以做什么

- **对话工作台**：发消息、上传材料、选择模型、排队或中途补充要求，查看公开工具和子 Agent 活动。
- **工作区管理**：打开已有目录或新建空工作区，各自保存对话、来源、稿件、评分与 Wiki。
- **对话整理**：归档、移到回收站、恢复，或批量归档已结束对话；报告、来源与 Wiki 不跟随对话清理删除。
- **从公开资料写简报**：不强制上传。开启联网后，由 Scout 查找并筛选资料；Analyst 写稿，Evaluator 独立评分。
- **直接改稿与学习**：编辑正文或留下反馈；Wiki Maintainer 整理经验，Skill Proposer 提出技能，Evaluator 比较实际产物后决定是否采用。
- **明确的预算与篇幅**：整次报告共享检索额度；正文目标字数和上限可直接修改。

## 第一次使用

1. 在“材料与需求”填写目的、读者、时间范围和字数要求。可上传材料，也可仅开启联网。
2. 选择搜索工具。Tavily 的输入口就在联网开关下；保存 Key 不会自动验证或发起收费搜索。
3. 在“设置”确认主模型及角色模型。模型 ID 可自行填写；可选 provider 名称沿用本机 Codex 已配置的 Responses provider，不限定 OpenAI 型号。
4. 点击生成。草稿保存后即可查看，评分独立完成；低分或评分失败不会隐藏原稿。
5. 按需修改正文、保存反馈或明确启动学习。注意自动学习开关：启用后，编辑静默约 30 秒会合并反馈并启动模型任务。

### 三个学习与评价角色

| 角色 | 职责 |
| --- | --- |
| Evaluator | 给产物评分；比较候选产物，判断是否改善 |
| Wiki Maintainer | 将反馈和执行经验整理成 Wiki |
| Skill Proposer | 根据 Wiki 提出或改进 Skill |

Evaluator 的单稿评分与产物比较共用角色配置，每次使用独立模型会话。候选技能已生成但验证未完成时，也能在 Wiki 页面查看；不会因为产生了文件就直接启用。

## 研究预算

| 预设 | 搜索调用尝试 | 去重候选 URL | 全文来源 URL |
| --- | ---: | ---: | ---: |
| 周报 | 12 | 60 | 18 |
| 月报 | 30 | 200 | 45 |

预算由整次报告中的 Scout 共享，不是每个 Scout 各拿一份，也不要求花完。失败的 Tavily Search 调用仍计次；同一 URL 的直接获取、Extract 回退及重试不重复扣全文 URL。达到额度后保留材料、说明缺口，不自动加额。

搜索请求和候选额度适用于受控 Tavily 工具；原生 Codex 搜索无法在此精确计量，页面会明确区分。全文额度统计受控工具处理的不同 URL，不是 PDF 页数、阅读完成数量或所有 HTTP 请求次数。

## 正文篇幅

| 预设 | 目标字数 | 字数上限 |
| --- | ---: | ---: |
| 简短 | 800 | 1,000 |
| 标准 | 1,500 | 2,000 |
| 详细 | 2,000 | 2,500 |

数字可直接修改。中文汉字每字计 1，连续英文或数字串计 1；格式、URL 和来源引用标记不计。原文摘录与定位放在来源记录中。页面显示保存后的实际计数，旧稿没有设置过数字要求时如实显示“未设置”。

## 开发

```sh
npm ci
npm run build
.venv/bin/python -m pip install --find-links vendor/wheels '.[dev]'
.venv/bin/python -m pytest -q
```

前端资源随包分发。服务启动时同时加载对应的前端和后端，构建或升级后需在任务结束后重启服务。开发测试不调用真实模型或 Tavily。
