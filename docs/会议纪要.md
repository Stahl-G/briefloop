# 会议纪要

在“新建报告 → 制作内容／用途”选择“会议纪要 · 会议记录整理”，或选用内置会议纪要模板并保持“使用建议用途”。内容方法负责整理记录和评价，Word 模板负责版式；仍可以显式选择其他方法或修改章节。

先添加并选中本次会议的转写或笔记。没有会议记录时，开启联网也不能替代它。议程与会前通知可以帮助整理框架，不能用来推测会上说过什么。首版不提供录音或语音转写服务。

## 整理规则

- 分开讨论意见、建议、明确决议、待办和未定事项。
- 识别同一事项的明确改口、更正或撤回；只因说话较晚，不能自动覆盖另一人的意见。
- 待办中的动作、负责人、期限均依据实际记录。没有指定时写明未指定或待确认；下次会议时间不能自动成为交付或验收期限。
- 关键决议和行动项保留原文位置或时间戳。外部背景不会被改写成参会者发言。
- 主章节默认沿用模板，章内可以用紧凑表格整理待办。用户明确修改结构时按本轮要求处理。

独立评价对照同一份已保存方法和原始记录。正确保留“未指定／待确认”不应被当作研究遗漏；材料已明确却未写入的决议或待办仍属于遗漏。初稿可见，自动修订与复核继续沿用现有设置。

## 示例与交付

[合成会议记录](../examples/meeting-minutes/transcript.txt) 包含交付数量和日期更正、未通过的加购建议、已确认与未确认的分工，以及下次会议时间。可以上传该文件，用 500 字左右、最多 750 字生成纪要，再逐项对照原文查看结果。

网页保留可编辑正文、待办表与引用，Word 按保存版本生成。普通下载是工作稿；正式交付仍遵循原有证据与独立审阅要求。该方法属于 0.20.0 之后的源码功能，不在已发布的 0.20.0 安装包中。

内置纪要模板使用紧凑标题，不再附一整页空白会议登记表。已知时间和参会者由实际记录写入正文；没有提供的地点、主持人等信息不会自动补成封面字段。
