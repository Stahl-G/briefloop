# 数据源库的归档与筛选

数据源库默认显示日常来源，最新入库的在前；可切换已归档/全部、报告、来源类型、发现渠道和读取状态。每次显示 50 条，继续加载只增加列表呈现数。正文搜索另行按有限候选分批扫描，显示扫描进度；“继续搜索”不等于“显示更多已有结果”。

归档是可恢复的资料库整理动作，不删除文件、不修改提取状态、不释放磁盘空间。单条菜单或多选操作均可归档和恢复，每次最多 200 条。旧报告、冻结任务、引文和原文快照继续使用原 source_id；归档不使旧证据失效，也不把它认证为新一期事实。

新页面初始化时，新报告的默认选材排除已归档来源。已经选择的来源保持选择，并显示归档标记；用户仍可显式选择已归档材料。归档不静默修改进行中的表单和任务。

按报告筛选使用该报告实际登记的 source_ids（包括后续研究取得的来源），不依赖首页最近几份报告的截断清单。报告选择器分批读取历史报告，当前热状态中的待成稿报告也可选；来源范围独立生效，查看某份旧报告的完整资料时可切换“全部来源”。

本次只限制 DOM 中呈现的行数；现有 state 中的来源元数据仍完整返回。没有自动归档、按日期删除、磁盘回收或新的模型调用。
