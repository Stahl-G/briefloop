# 行业定期报告

行业报告复用 BriefLoop 的对话、Scout、Analyst、Evaluator 和 WikiSkill。它提供可调整的报告要求、结构化指标计算、数据缺口查看和正式 Word 输出，不绑定任何公司或行业，也不创建额外的必经审稿角色。

## 从网页开始

1. 打开“材料与需求”，选择“行业定期报告”。填写行业、目标组织、研究目的、报告日期与覆盖期间；不适用的字段可留空。
2. 默认目标 5,000、上限 5,500 个中英混合计数单位，可直接改。普通简报仍保留原有篇幅预设。
3. 可以上传现有资料或表格，也可以开启联网让 Scout 查找。历史成稿可单独勾选为“结构与风格参考”，不会同时进入本期证据。历史数据若需要参与本期比较，应作为证据材料提供并明确日期，不能同时选作风格参考。
4. 确认主模型、角色模型和整次研究预算后生成。关键证据不足时，Analyst 可请 Orchestrator 在剩余预算内安排一次定向补查；没有新资料也要交付已有结果与缺口。
5. 在报告页查看正文和独立评分。“数据与缺口”读取已保存的原始值、比较口径、计算结果和缺口，不调用模型。
6. 下载 Word。行业模式使用内置 A4 蓝色版式；标题、组织与日期来自本轮需求。历史 Word 用于学习文字结构，不等于导入其任意模板、图表和全部样式。

建议章节包括摘要、关键指标与供应链、供需竞争、重点专题和组织启示。按行业调整，不要求每个行业都有金融指标或资本运作建议。模板不要求凑齐表格数量。

## 缺少资料时如何交付

报告应说明缺少什么指标或原文、最近可得日期、影响哪些结论、建议补充什么来源。没有更新不自动等于没有变化。预测、公司指引、市场一致预期与实际统计须明确区分；报告发布日期不等于所有数据的截至日。

空的缺口列表不表示完整覆盖或已全部核验。程序能检查记录结构、来源归属和计算规则，不能凭计算成功证明原始数值真实；Evaluator 仍应对照原文。

## 数据与外部 Agent 接口

普通用户不必编写 JSON。Agent 可从已上传表格或已登记公开原文整理指标。外部工具也可下载 `/api/report-data-template` 空数据模板和 `/api/report-data-schema` 字段说明。

原始格式为 `schema_version: industry_periodic.v1` 与 `records` 数组。每行至少包含 `metric`、`unit`、`current_date`、`source_id`。`current` 可为 null，表示缺值；完全没有来源的缺口写在稿件 `gaps`，不要虚构来源 ID。

常用字段：

| 字段 | 用途 |
| --- | --- |
| product / region / tax_basis | 产品、地区与税口径 |
| current / current_date | 本期值及指标所属日期或预测期间 |
| as_of | 预测、指引或一致预期的发布/截至日，与预测期间分开 |
| previous / previous_date / previous_as_of | 比较值、指标期间、数据截至日 |
| source_id / locator | 本期已登记原文与定位 |
| previous_source_id / previous_locator | 比较值的原文与定位，可与本期相同 |
| category / previous_category | actual、forecast、guidance、consensus |
| comparison | pct、bp、difference、none |
| comparable | 是否已核对两组产品、地区、期间与口径可比 |
| previous_unit / previous_tax_basis | 明确比较值单位与税口径 |

百分比变化按 `(current - previous) / abs(previous) × 100` 计算；基点模式输入使用百分数，例如 `4.5` 表示 `4.5%`。零分母、不同单位、未确认可比或日期方向错误会形成缺口，不伪造变化率。

```sh
briefloop tool --workspace /path/to/workspace prepare-report-data \
  --run RUN_ID --file raw-data.json --output prepared-data.json
```

工具返回原始记录、`calculations`、`gaps` 和可用于报告的 Markdown 表。它不会创建新的事实来源或调用模型。记录引用必须属于本轮已成功读取的证据，风格参考不能用于事实表。

Agent 将原始 `schema_version`、`records` 放入 `draft.report_data`；不要把含计算字段的整个 prepared 对象塞回去。最终草稿仍通过既有发布路径保存。Evaluator 同时获得原始数据、重算结果和对应来源。

## 输出与修改边界

Word 支持封面、A4、蓝色标题、表头重复、浅色隔行、页眉日期、组织页脚页码及真实网页超链接。有 2–24 个同指标、单位、地区、产品、税口径、同一 as_of 的预测点时，附一张预测趋势图；重复日期、缺少截至日或不适合制图时不造图。目前只选一条符合条件且记录最多的系列，不是通用图表编辑器。

手动修订正文不会自动改写原始指标。数字有变化时，原数据保留供查看和评价，Word 暂不附旧数据图，避免让图与修订稿产生无提示的冲突。普通措辞修改保留图表。

本轮验证使用合成输入，覆盖真实保存、计算工具、HTTP 下载和浏览器操作。未运行收费研究任务；真实行业资料覆盖、分析质量和模型成本仍需实际任务验证。
