# 0.26.0 发行候选

本文件描述待发布候选，不表示 GitHub Release、PyPI 或桌面安装包已经更新。实际发行须从最终冻结提交生成同一份后端 wheel，再完成目标渠道验收。

## 本轮范围

- 快速报告：已有材料直接出稿，或先进行有预算的联网取材。首稿可立即编辑下载，后台补依据与普通评价，用户编辑优先；不额外限制来源输入字符数，不因长度静默丢材料。目标用时不是运行中断条件。
- 依据与核查：正文原句绑定来源摘录，补充来源标题、章节、邻行及表头；数值检查显示已提交绑定的可核对比例。日期、主体、状态、范围、摘要和推论在已有评价中单列核查，未查不冒充通过。独立审阅展示逐条结论判断及未核查事项。
- 可选 Jev：用户主动查看发送范围并触发依据预检，结果按版本保存，仅作待复核观察，不改变正式交付条件。见 [Jev 使用说明](jev-precheck.md)。
- Native 与研究：故障恢复、写稿回执和实际篇幅口径继续完善；研究交接保留来源定位与采用条件，已开启研究轮明确收尾后再写稿。没有新增默认研究轮次或预算。
- 报告篇幅：默认目标与用户明确要求的严格上限分开，保留上限来源；英文按词显示，控制状态随版本与回执可追溯。
- 模板与阅读：Word/已有报告可作为模板入口，转换保留表格位置及用户选择的导出版本；不支持的分页结构明确拒收，失败后可恢复；正文抽屉与工具栏布局统一，导出不展示抓取器内部行号。
- 模型与运行：模型目录按需刷新、读取档位能力；本机来源读取支持现有后台任务与失败状态。Windows UTF-8 的读写与锁修复纳入共享代码；SQLite 争用工具仍只负责测量，未擅自切换 WAL。
- 语义实验：保留 Jev/LLM 选择与概率对照、开发与留出绑定、人工标注边界。实验结果不能自动改变事实、交付或学习状态。

## 发行前剩余检查

1. 相关代码、构建和页面路径检查；一次小型真实快速流程，区分首次成稿与后台完成。
2. Jev 使用实际 TypeSafe 凭据的连接与结果保存验收。离线合成响应不算真实服务通过。
3. 最终冻结提交构建一次 wheel；Mac/Windows 目标安装包复用。按本轮平台范围完成原生启动、保存、导出及更新检查。
4. 发布已验证工件，更新官网与更新索引，并从 GitHub/PyPI/下载页重新核验。暂不就绪的平台单独标明。

不将小样本实验包装成稳定提速、事实正确率或成本优势；0.25.0 的旧渠道记录保留，不用新版本文件覆盖旧发行。
