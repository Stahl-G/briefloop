# 证券研究

在新建报告中选择“证券研究”，再选择事件点评、公司研究或行业跟踪。使用内置券商研报模板时默认建议事件点评，也可以显式修改用途。Word 版式和内容方法分别选择；每次任务固定所用方法，修订和独立评价读取同一版本。

提供标的、期间、核心问题和材料；允许联网时可以定向补查。优先使用公司披露、交易数据和原始研究报告，记录指标定义与数据时点。单份卖方研报按该机构预测处理，不自动称为一致预期。

- 事件点评解释相对先前披露或明确预期发生的变化及影响。
- 公司研究组织业务、利润与现金流驱动、竞争位置及有依据的估值。
- 行业跟踪解释供需、价格成本及重点对象的差异。

正文和图表分清实际值、指引、预测与情景；计算由现有数据工具完成。估值所需价格、股本、盈利期间或净债务缺失时不能捏造目标价。模板默认保留具体风险分析，取消固定免责声明及空白评级／目标价表；用户明确需要的披露与评级按其要求及实际依据处理。

[合成事件材料](../examples/stock-research/earnings-event.txt) 包含季度变化、全年指引与单家卖方预测，适合离线核验口径、同比和毛利率百分点。建议用事件点评生成一份 800 字左右、含趋势图和精确指标表的稿件。它是虚构的开发验收材料，不代表任何真实证券。

网页支持正文、图表、来源与版本编辑，Word 在点击后按保存版本生成。普通稿件可以下载；正式交付继续受证据与独立审阅约束。该能力位于 0.20.0 之后的源码，未包含在已发布 0.20.0 安装包中。
