# BriefLoop 0.31.0

本页说明本轮变更；渠道发布与安装状态以正式发行清单为准，开发分支上的文档不表示已经发布。

## 本轮改进

**行业季报（试用）。** 商业报告新增「行业季报（趋势与格局变化）」。季度报告的价值在于看清一个季度里的变化方向，所以方法是：先做一次行业全景扫描，再由模型挑出值得跟踪的 8–15 家公司、国家或模型，给每个主体立期初状态，最后查期内变化。变化写进状态表，程序核对期初、期末两端是否有来源，日期是否落在报告期内。普通的升级、降价、范围扩大记为“状态改变”；只有“加速”“停滞”这类判断需要另外给出可比依据。中文正文软目标 8,000–10,000 字。真实试跑已能完整生成、评价和修订，但季度起点证据仍常不足，正式交付前需要人工核对。设计见 [行业季报](quarterly-report.md)。

**直写（试用）。** 新增一种研究方式：一位作者在同一会话里，用本轮计量的搜索、读取工具完成研究和写作。保存后照常定位证据、独立评价，并自动修订一次。默认仍为分轮研究。见 [直写模式](direct-mode.md)。

**读取更多原文。** 网页本地读取失败且已配置 Tavily 时，用 Tavily 提取正文补读，计入本轮页面额度，失败记录保留。SEC EDGAR 要求请求方声明联系方式；可在 设置 › 搜索 填写联系邮箱，只发送给 sec.gov。

**更少的整次失败。** 评价引文无法在稿件里定位时，先在同一会话修一次，仍无法定位则只去掉该锚点、保留问题本身，不再让整次检查失败。修订不再采用写作模型自拟的读者契约。大网页按引用窗口限量发送，避免请求过大被拒。后台评价中的自动修订改由 Analyst 执行。

**目标驱动研究。** 内置引擎的主 Agent 可直接使用受控搜索和读取；CLI 宿主在没有 Scout 时也能把材料交接给 Analyst。既没有搜索也没有新来源的轮次，须写明停止原因。

**提示词与内部清理。** 内置引擎的角色提示词去掉了与工具说明重复的参数规则，并消除摘录写法上的前后矛盾。两个题目的真实对照里，评分和重大问题数没有变化。同时删除约 1,500 个只复述实现的测试，以及对仅由本程序写入的记录做的自校验哈希。

详细变化见 [变更记录](../CHANGELOG.md)。

## 发行一致性

Mac、Windows、Python/CLI 复用同一冻结提交构建的一份后端 wheel。各平台分别完成实际启动、保存、导出和升级核验后统一公开；未完成的平台单独标注所处版本。安装包未签名、未公证。
