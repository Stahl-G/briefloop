# 同一对话切换宿主

输入区的「下一回合宿主」用于选择接下来发送消息的 CLI。选择宿主后，再选择或输入它支持的模型。切换只作用于此对话的后续消息，不修改工作区的报告与学习默认模型。

正在执行的回合继续使用原宿主。可以选择其他宿主并排队发送，已排队的消息保留提交时的模型、权限与联网设置，按提交顺序执行。「当前」显示实际执行宿主；停止按钮停止当前回合，同时取消尚未执行的排队消息。运行中追加仅在当前宿主支持且未切换目标时可用。

切换时，BriefLoop 为新宿主准备本对话的可见用户消息、助手回答和已有材料 ID，不传递隐藏推理或内部提示词。返回此前使用过的宿主也会建立新原生会话，带入期间形成的可见历史。既有稿件与材料仍保存在同一工作区。

同宿主继续对话时，只有模型、目录、权限、联网设置和原生历史仍匹配才续用原生会话。原生句柄缺失、前一回合中断或可见历史来自其他执行时，会重新带入可见历史。服务重开不会自动重放已开始但未完成的消息；用户可以查看保留下来的失败或中断记录后继续发送。

报告任务对话沿用生成时冻结的宿主，不能通过这个入口改变正在运行的研究、审阅或修订任务。历史无法完整交接时会显示错误并保留排队消息，用户可停止队列并新建对话。
