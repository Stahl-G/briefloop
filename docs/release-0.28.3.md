# BriefLoop 0.28.3

本次发行包含 Pi 1.0.0 升级与兼容修复 #888、版本说明页 #887、定期报告实验离线预检 #873。下一期报告 #870 及评分实验 #855 / #857 保留在各自分支，尚未通过的验收不作为本版质量承诺。

原生引擎保留角色工具隔离和旧会话恢复，适配压缩指令的 transcript 接口，随包提供图像 worker 与 Photon WASM。修复 5000×1 / 1×5000 图片缩放被遗漏的问题，关闭长子任务期间默认缓存预热，保证请求与用量事件一致。原生引擎使用固定 pnpm 锁及修复后的 brace-expansion；前端和桌面继续使用 npm。

三个 PR 的组合已通过 1283 项 Python 测试（65 跳过）、246 项前端测试（3 跳过）、构建与 design:check，47 项原生引擎回归和依赖审计零告警。版本说明页的 1440px 和 768px 实际浏览器截图已核验；检查更新可用，当前说明与 wheel / sdist 中的资源一致。Pi 升级最终提交的 Linux、macOS、Windows 六项 CI 全通过。

用户已授权合并、GitHub Release、PyPI、官网及可访问的本机安装更新，保留旧版回退。发行从干净冻结提交构建，共用后端 wheel 仅构建一次，所有渠道复用相同字节。发行工件哈希、平台验收和发布后渠道状态随本版验证记录披露。

发行验收另复现并修复了桌面正常停止后端的 stdin 交接问题：原行为使 Python 以 SIGABRT 退出；收到正式停止接口的成功回执后关闭 owner 管道，实际 Python / Electron 组合恢复正常退出。忙任务拒绝停止时保留管道及服务。安装包验收脚本直接加载实际 ASAR 模块，检查随包环境、Pi 1.0、版本说明、正常退出，以及两种涨跌惯例和 agent / user 合成稿的八份 Word / Excel 产物；不调用模型、不替代原生窗口或办公软件操作验收。
