# 图文资料与下一期报告

开发中的 0.29.0 能力，尚不表示已发行。

## 从现有入口开始

“新建报告”打开普通对话，可以直接说需求、添加材料。首页“导入旧报告”沿用现有 Word/Markdown/TXT 导入，保留 Word 修订记录；“自己填写要求”仍可打开完整表单。

报告页的“开始下一期”准备一条未发送的对话，显示所选报告。只需补本期时间、重点变化或材料；约定从该报告的已保存版本读取，当前回合使用自己的模型、材料、联网和费用选择。点击入口不会启动任务。可以取消关联；刷新会恢复尚未发送的关联草稿。

## 本地图文资料

直接用附件或数据源的文件入口上传：

- 含一篇 Markdown 或 HTML 正文及其图片的 ZIP。图片按正文里的相对链接对应，无需编写清单。目录关系应保留。
- Link2Context 0.1 的 `context.json`。如已有图文资料包，可连同包内图片及对应关系一起上传 ZIP。

一次 ZIP 对应一篇正文，多篇请分别上传。当前沿用来源上传的文件大小上限；不在线下载缺图、不执行包内脚本、不自动运行 OCR。原始 ZIP/JSON 会保留。

来源面板展示正文、发布信息、每张原图的原始图号和读取状态。展开一项才加载其预览。相同字节的图片会提示核对用途，不据此认定其内容真假。缺图、损坏及不支持的图像格式明确列出；图片可解码不代表模型已经查看或理解。PNG、JPEG、WebP 使用现有媒体校验；其他格式保留在原件内。

Link2Context 的远端图片 URL 本身不能证明本地缓存对应关系。包内的 `local_path` 必须是相对路径；已有按文章标题索引的 `media-map.json` 可对应 `doc<ID>-image<图号>-<hash>` 缓存文件。找不到对应关系时保留缺口，不根据目录里相似的图片名猜配。独立上传 context.json 不会读取其中的外部本机路径。

## 方法和学习

经营复盘及决策分析沿用既有文档方法快照。新方法强调期间与口径可比、分项归因不重复、差额与总数冲突保留，以及投入/合同额/利润等 ROI 口径区分。旧任务继续使用其冻结方法。

保存改稿、模型整理反馈、候选技能启用和下期效果是不同结果。学习仍遵守当前工作区预算授权；事实纠错不能变成通用写作规则。真实效果对照尚待完成，不以静态检查或方法文本变化宣称报告质量已提高。
