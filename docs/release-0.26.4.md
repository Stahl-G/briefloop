# BriefLoop 0.26.4

本版在 0.26.3 统一发行基础上合入 PR #850。App 更新后自动准备新后端，首次安装与修复仍需用户点击。报告页简化工具栏、提供来源列表与分组检查结果，保持统一设计令牌。

合并审查移除了未判断进程占用的旧环境自动删除。旧环境保留，避免破坏独立 CLI 任务。

从同一冻结提交构建一次后端 wheel，Mac、Windows 与 PyPI 复用。正式工件不在发布阶段重建。按维护者要求停止追加测试；0.26.3 已做的原生检查仅作历史记录，不冒充本版升级流程验收。已有 CI 和未完成的原生更新覆盖在发行说明中分别列明。

发布后同步官方渠道与实际安装；候选使用预发行编号，不再以正式版号装入日常环境。Mac 未作 Developer ID 签名或公证，Windows 安装包未签名。
