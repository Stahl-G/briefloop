# 默认行为与可选能力

日常入口继续使用默认自主直写。这里区分默认执行、按内容显示、需要选择和尚未完成的能力，避免把高级菜单收起当成关闭。
本轮没有更换产品版本、发布渠道或安装程序。

## 补齐已有默认路径

| 能力 | 行为 | 限制与验证范围 |
|---|---|---|
| 人工改稿后的自动学习 | 新工作区首次选择模型时默认勾选，开始使用时确认真实调用预算；既有关闭选择保留 | K 默认 1，候选经过分类和比较才能采用。已有合成闭环证明采用及下期送达，尚不证明连续真实周报的稳定收益 |
| 报告反馈继续补查 | Native 报告聊天与其他宿主一样，在该消息获准联网后提供实际搜索、网页读取工具 | 绑定本消息、原稿版本与剩余预算；普通聊天、只读讨论、离线反馈不会取得该权限，完成或中断后失效 |
| 直写稿独立事实核查 | 已有依据补全调用选择最多 12 条公开事实候选，定位到正文与原件后进入默认核查流程 | 候选不是正确性判定；联网核查及独立审阅仍各自执行。只处理可确认的匿名公开 HTTP 原件，混有未确认材料时不自动提取 |
| 核查缺口显示 | 检查栏显示当前版本未进入核查的原因 | 旧稿原因不覆盖新稿，真实结果和正在执行的阶段优先；不往报告正文追加流程声明 |
| 失败检查恢复 | 绑定原稿的检查可按当前模型新建重试，保留失败记录 | 只重做检查，正文不变；实际模型和思考档位单独记录 |

公开原件准入当前不包含上传文件、连接器或通用提供方响应，也不接受含凭据、查询参数或片段的地址。
空内容的失败公开抓取不会阻断同报告其他有效原件，但不能作为候选依据。已有标准流程及手动登记的主张维持原有行为。
候选选择仍会遗漏事实；没有候选、搜索额度不足或检查未完成都不能显示为整稿核实。
自动派发和实际执行前会复核公开资料范围，失效的旧稿绑定不进入新版核查。
事实核查查询可以查历史背景，不被本期新闻窗口覆盖；普通 Tavily 研究按 UTC 日期扩大到覆盖边界，报告自身时间范围保持原值。

## 已有默认功能

| 范围 | 默认或按内容显示的能力 |
|---|---|
| 报告入口 | 对话创建报告、普通新请求自主直写；连接器、企业内部报告、独立风格参考、行业季报及外部 Pi 按既有适配走标准流程 |
| 任务参数 | 允许联网、任务时间冻结、按期间建议篇幅与预算；手工指定的值优先 |
| 保存与资料 | 自动保存编辑、历史版本、来源快照、引用定位、来源检索与归档、发布与收录日期区分 |
| 检查 | 普通评价、数值和日期的确定性检查、具备能力时的独立事实核查、生成流程的一次自动修订 |
| 修订 | 版本绑定的反馈、保留原稿、正文修改后移除失效依据、直写聊天改稿后的依据重建与评价；该收尾不重复改写正文 |
| 阅读与输出 | 编辑器、表格和粗体、引用与来源侧栏、重大问题标记、大纲、Word 下载及其他格式菜单；未完成检查不封锁普通工作稿下载 |
| 后续报告 | 用户启动下一期后沿用结构与已采用方法、明确保存的写作约定；当期事实重新获取 |
| 引擎 | 作者角色上下文压缩、过程记录、受控重试、中断保留与恢复；Pi SDK 已整合至 1.2.0 |

来源图片与 PDF 页面按需加载。右栏、技术详情、检查记录和历史记录依据现有内容显示，空态不占位。
计划报告在用户创建后默认启用；产品不会替用户新建计划。旧任务没有生成方式字段时仍按旧标准流程恢复。

## 保留可选的功能

| 能力 | 继续保留选择的理由 |
|---|---|
| OfficeCLI 检查与 Excel 增强 | 本地实测能发现除零、无效工作表引用与非法字号，但干净 Word 的普通署名段也收到缩进建议；单次额外约 4–5 秒。一个开关同时控制检查和 Excel 增强，未证明整组默认开启的净收益 |
| 目标驱动研究策略 | 既有同条件实验更快，但部分主题关键覆盖下降。继续试用，未因速度单项切为默认 |
| 快速写作、深研究、严格字数 | 分别改变材料范围、费用或内容取舍；未取得通用报告质量不降的对照证据 |
| 建议句黄色标记 | 属于阅读显示偏好，可能增加噪声；重大问题标红已经开启 |
| 附加搜索渠道、更多学习轮数、额外核查额度 | 影响外发范围、调用量及费用，使用既有明确选择与预算流程 |
| Jev 语义预检 | 独立服务，旧实验不足以证明判断收益；不会自动增加服务调用 |
| 企业背景、读者档案、模板与风格参考 | 需要知道本报告用途和材料范围；不存在适合所有报告的默认企业或读者 |
| 来源更新、下一期、定时任务 | 明确任务后执行，来源新披露与旧稿事实错误分别处理 |
| MCP 材料与外部工具 | 只使用选定连接器与材料，不因 SDK 支持而自动扩大权限 |
| 正式交付与审计包 | 用户按需触发，正式交付仍绑定独立审阅与来源版本；普通下载继续可用 |
| 桌面自动下载、退出安装、诊断、系统拼写检查 | 属于安装、系统或个人偏好，保持已有选择；不改变研究默认 |
| 隐式缓存预热、Pi 任意 Shell、自动加载个人扩展 | 会增加调用或工具范围；现有角色隔离、指定工具和加载边界保持 |
| Reviewer / Evaluator 自动压缩 | 检查角色使用固定证据包，不默认用摘要替换待核对材料 |

读者专属技能的跨读者适用性和完整留出验证尚未完成，不能通过翻转开关视为完成。
深色主题等缺少完整实现的界面能力也不属于“已做好却关闭”。

## 如何判断下一项该默认开启

先确认用户主路径是否实际调用该能力，再以一份真实产物验证它减少了什么错误或返工，同时记录新增耗时、调用和误报。
与已启用功能重叠的检查先合并入口；权限范围或交付行为不同的能力保留明确选择。
模型分数、候选采用或工具成功各有范围，不能单独代替正文质量、事实正确性或长期学习收益。
