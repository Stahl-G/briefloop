# 运行时选择与检测

在“设置 → 模型与提供商 → 本机 CLI”查看运行时。每张卡片展示本地图标、简介、实际检测版本；选中项显示模型，其他项不会沿用当前宿主的模型名称。展开“安装与能力”可以查看路径、连接方式与已接入能力。

未安装工具放在折叠列表里，展开后用双列卡片浏览，窄屏使用单列。没有品牌图片的工具使用中性的终端图形。

- **已检测到**：找到可执行文件，可以选择宿主；账号和模型是否能调用，请使用卡片中的“测试”。
- **已有适配 · 安装后可测试**：BriefLoop 有相应协议适配，本机还没检测到 CLI。安装后点击“重新检测”，再选择模型并测试。
- **尚无协议适配**：目录能够识别工具，但该版本没有接通其执行协议；仅安装工具不能开启执行。

ACP 是共用连接协议，但每个 CLI 仍有自己的启动命令、登录方式与能力协商。Kilo、Kiro、Vibe 复用现有 ACP Bridge；本轮接通了设置和执行入口，尚未安装的运行时不会显示为真实测试通过。受限审阅等能力仍由宿主实际权限决定。

模型列表来自该宿主返回的目录、本机配置或明确标出的内置建议，也可输入模型 ID。选择目录中的模型不表示已验证账号权限。点击“测试”后会打开普通对话，显示回复、错误或停止状态；真实请求可能消耗所配置提供商的额度。

首页的宿主选择器用于下一回合；已经开始或排队的回合保留冻结配置。运行时名称仍可在该回合的执行信息中查看。
