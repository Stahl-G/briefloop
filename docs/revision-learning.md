# 修订学习闭环（#858）

保存与学习分开。保存原稿、改稿、评论及导入 Word 修订不启动模型；开始学习时，确认界面列出一次独立分类会话和每轮整理、提案、比较与试写上限。会话数不是宿主内部回合、Token 或费用上限。旧预算未包含分类调用时暂停，原任务与反馈保留；“确认预算后重试”创建关联的新尝试。

## 当前行为

- 按正文块拆分改动，Evaluator 对照来源判断口味、事实纠错、读者特定，保留理由与判断者。事实纠错不进入写作技能。所有不确定改动先隔离；较大改动集中提问，小改动在经验页可选确认。人工确认只作为新的反馈消费一次。
- 读者档案只记录名称、决策用途与偏好，报告冻结当时档案，刷新保持选择。读者专属反馈保留待学习，不进入全局技能；历史独立读者技能及其派生版本不能全局启用，原记录保留。
- 离线比较保留的候选仍可按原机制用于报告，但“用于报告”和“证明跨期有效”是两个状态。后续单次模型标记只显示初步线索；交付、空 repeats、跳过及未评估均不证明未复发。不自动标为已采用或没有改善，不编造基线和复发率。
- 导入 MD/TXT/DOCX 可提出读者、结构与口径约定，用户确认后使用。未出现的内容不推定为禁区。Word 插入/删除文本及整行修订保存前后版本，表格保留行列文本。导入文件只作约定和写法参考，不能自动作为本期证据或事实引用；原件仍保留。
