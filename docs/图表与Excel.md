# 正文图表与 Excel 复用

主 Agent 根据任务目标、历史报告、数据和读者决定图表类型、数量及位置。精确数值和条件比较适合表格，趋势、量价和事件变化适合图；不为了版面凑图。程序只负责保存、引用和呈现，不固定成一种预测图。

## 复用已有图表

上传 XLSX 后保留原工作簿，并读取单元格保存值，公式不自动重算。以下命令提取内嵌图片的原始字节，并列出原生图表的标题、工作表和锚点：

```sh
briefloop tool --workspace WORKSPACE extract-workbook-figures --id SOURCE_ID
```

- 内嵌图片：直接得到图像文件，可查看并登记。
- 原生 Excel 图表：文件中保存的是图表定义和数据引用，没有现成 PNG。应使用可用的工作簿渲染工具，或经核对来自同版本工作簿的已有渲染。这个命令不会假装已把它渲染成图片。
- 重新绘图：在没有合适原图或需要新视角时使用，保留原始数据和脚本，不能称作原图复制。

若没有可用的原生图表渲染器，明确说明该项限制。当前没有把商业 Office 或私有 artifact runtime 作为公共仓库的隐含依赖。

## 登记并插入

图片、数据及脚本放在当前工作区内：

```sh
briefloop tool --workspace WORKSPACE register-figure \
  --run RUN_ID --image chart.png --title "图表标题" \
  --caption "日期、单位与必要说明" --source SOURCE_ID \
  --data chart-data.csv --script build-chart.py
```

登记只保存快照，不运行传入的脚本，不决定图表内容。复制原图时，data可以保存工作表、图表定义和数据定位的JSON，script保存提取或渲染步骤。

把返回的 `![标题](briefloop-figure:FIG_ID)` 放在稿件对应段落。网页编辑器显示图像并保持保存往返；Word在相同位置嵌图、图注和来源。源文件与生成图片有哈希和来源记录；这提供追溯，不等于图中每个数值已经正确。

## 下载与修订

- Word：图表作为图片嵌入，可复制，但不承诺变成可编辑的 Word 原生图表。需要改数据时保留原 Excel 或生成脚本。
- 图文包：ZIP包含report.md与assets图片，可以离线携带；普通Markdown文件中的内部图表引用只在工作区中有意义。
- 原稿保留。补图会形成新版本，旧评分仍对应旧稿，不自动当作新版图表已经通过评价。
- 用户更改正文数字不会自动更改已登记图像；需要更新图表时重新登记并引用新版本。Evaluator可读取图像、数据及脚本依据核对一致性。

本功能不绑定任何公司或行业；私人工作簿、原图和数据只保存在用户工作区。
