# BriefLoop 0.31.1

本页说明本轮变更；渠道发布与安装状态以正式发行清单为准。

## 主要变化

**少一些声明，多写清事实。** 报告作者把核查状态写成有依据的事实，减少面向审阅者的声明、过程叙述和重复免责。影响判断的证据缺口、范围与条件仍保留。这项写作改动来自 #920。

**直写收到实际选用的经验。** 修复直写模式未把已选 WikiSkill 送达作者的问题。任务保存选用方法与宿主实际输入的绑定；学习比较和采用前核对送达证据，缺少证据时保留候选并拒绝采用。比较使用同一冻结作者代码。送达核对不代表作者已遵循方法或报告质量已经提升。见 [直写模式](direct-mode.md)。

**保存正文与日期依据。** 直写稿件保存保留正文粗体与作者提供的日期依据。证据补充沿用已保存日期信息，来源抓取日期从来源记录取得；缺少的字段保持空缺。

**内置引擎更新。** BriefLoop Agent 使用 Pi 1.1.0，保留既有角色工具隔离、会话恢复、取消、上下文压缩和图片处理。长子任务期间的隐式缓存预热保持关闭。本轮升级没有开启 Pi 的 MCP、codemode 或个人技能加载。

**检索入口沿用冻结策略。** 修复宿主直写命令示例没有指定受控搜索 provider 的问题。作者按冻结首选与缺口补查规则检索，受控请求明确选择已允许渠道，共用本轮预算；入口不会自动改选其他搜索服务。

## 升级说明

本版延续现有工作区、稿件与会话数据，默认研究方式仍为分轮研究，直写继续按试用提供。更新前结束正在执行的任务，再按正式渠道更新；新任务使用本版写作和检索入口。已有稿件与冻结记录保持其原有版本和输入。

Mac、Windows、Python/CLI 从同一冻结提交复用一份后端 wheel。各平台实际启动、保存、导出和升级核验分别记录，正式发布状态以发行清单为准。

详细变化见 [变更记录](../CHANGELOG.md)。
