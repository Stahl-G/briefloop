# BriefLoop v0.15.1 — Prepared Release Target

This document describes the prepared v0.15.1 target. It is not a claim that a
git tag or GitHub Release has been created. The target extends the fresh
SQLite/Codex path with two experimental surfaces: a Store-qualified AI Second
Opinion review loop, and a schema-18 Solar Stock Periodic source-discovery
ReportPack.

## What changed

- AI Second Opinion can append multiple Human-authorized assessment generations
  against one finalized report, bind each result to its verified archive, and
  expose exact replay/projection state through the secured local Review
  Session.
- Human-originated observations are first-class append-only records. They can
  be superseded explicitly, turned into guidance drafts, and approved in a
  separate Human action. They are advisory context, not evidence, Gates,
  automatic learning, or delivery authority.
- Schema 18 adds frozen multi-search plans and immutable Tavily acquisition
  bundles for `solar-stock-periodic`. The default plan has 20 independent tasks
  (11 listed companies, 5 event-only entities, and 4 themes), up to 20 Search
  results per task, grouped Extract batches, one conditional 30-day backfill,
  and an 800-unique-URL safety envelope.
- Public documentation and runtime skills now describe the same boundaries,
  including the fresh-only rule and the removal of the old one-query/five-URL
  execution path.

## What it does not claim

This target does not prove semantic truth, investment outcomes, provider
reliability, or report completeness. Search snippets are discovery material,
not Claim Ledger evidence. Live Tavily usefulness, coverage, cost, and
acquisition-to-finalization performance are **NOT MEASURED**.

The Solar Stock Periodic contract reserves a market-data snapshot boundary for
prices, returns, FX, and valuation fields, but the v0.15.1 target does not ship
a YahooMarketDataAdapter. Missing or conflicting market data must remain
visible; the runtime must not fill it with invented values. Existing schema-17
workspaces are not migrated; use a fresh schema-18 workspace.

## Validation

The target was checked with focused Tavily acquisition, ReportPack, Reader
Review, Human Observation, skill-projection, and static-asset tests. These
checks exercise contracts and deterministic control behavior; they do not call
a live Tavily/Yahoo provider or establish production model quality.
