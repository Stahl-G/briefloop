# 定时报告

在首页的“定时报告”中选择“新建计划”。可以使用每天、每周、每月预设，也可以自定义每 N 分钟、小时、天或周。填写首次执行时间和时区后，点击“预览下次时间”核对，再保存。

计划包含报告标题、需求、选定材料和联网选择；创建时沿用当前已保存需求中的模板、读者、篇幅、人工填写章节与研究预算。先在“新建报告”中设置这些要求，再创建计划。编辑已有计划不会因为其他报告的设置变化而改写需求。

每次执行会更新报告日期和滚动时间窗，并采用执行时工作区当前的模型、宿主、角色配置和已启用技能，冻结到该次任务。模型执行仍使用对应服务的额度，定时功能不会免除模型费用。仅使用所选来源 ID；当期新搜集的材料不会自动列为下一期的已选来源。需要更新材料时可编辑计划。

## 执行时间

- 每天、每周按照所选时区的当地时间；每周使用首次执行日的星期。
- 每月使用首次执行日期；当月没有该日时使用最后一天，下个月仍按原始日期计算。
- 自定义频率按实际经过的时间计算，例如每 24 小时可能在夏令时切换后改变当地钟点。
- 当地夏令时重复时点执行一次；后续遇到不存在的钟点顺延。首次设置若落在不存在的时间会提示重新选择。
- 调度器约每 15 秒检查一次，到时进入现有任务队列，实际开始取决于前面的任务。

只有工作区服务运行期间才会执行。App 退出、CLI 服务停止或电脑关机期间不会运行；重开服务跳过已经错过的时点，不集中补跑。不安装系统定时任务、不自动唤醒电脑。电脑休眠期间无法执行；保持进程而从休眠恢复时，最多接纳一次已到期报告，随后计算下一时点。

同一个计划的上一份任务仍排队或运行时，新的时点会记录为跳过，避免堆积。首页可暂停、启用、编辑、删除或立即运行。暂停和删除只影响后续触发，不会删除成稿或取消已经开始的任务。若要停止当前任务，可点击计划卡片的“停止本次”。

## 与 WikiSkill 配合

定时报告与手动报告共用生成、独立评价、一次自动修订和 WikiSkill 学习流程。用户改稿与反馈按现有设置进入学习；验证通过并启用的新技能可在下一期使用。每份报告保留它使用的技能版本，旧稿不随更新改变。

定时生成次数不代表学习收益；上一期报告和 Wiki 中的经验不能代替本期证据。企业内部报告仍要求提前选择是否维护企业背景知识库。

## 结果与失败

首页显示计划的最近执行状态及可用成稿；也可以在“我的报告”和任务列表继续查看、编辑、核查、导出 Word。生成失败或中断时保留已有结果与错误，调度器不会自动重试这次失败。宿主自身的限流重试会显示等待原因，可用“停止本次”结束等待。修正材料或模型配置后可选择“立即运行”。
