# BriefLoop 0.31.4

这次更新收敛报告入口，并补齐改稿、核查和经验学习之间的连接。

- **新报告减少模式选择。** 保留材料范围、研究投入和篇幅；普通报告默认自主直写，季度、连接器等任务自动选择所需流程，已保存任务的配置保持。
- **BriefLoop Agent 使用 Pi 1.2.0。** Native 思考档位正确传递，修订材料减少重复，原稿、来源及问题记录保留。
- **改稿后继续检查。** 反馈与实际消息、稿件版本绑定；只改引用也进入待复查。检查失败重试复用同正文的证据子稿，核查预算只能追加到对应版本。
- **经验学习更容易发现。** 新工作区默认选择学习意图，首次确认调用预算后才执行；旧工作区关闭选择保留，候选方法仍须经过验证才能采用。
- **数字可通过已有 Jev 接口做语义核查。** 不必先满足 Python 的单位解析；发送前可预览原句及来源，上下文只解释待核查句，不作为证据。仍由用户主动启动，结果与机械核查分别展示。
- **日常体验修复。** 设置页返回原页面和滚动位置；Windows 接受带 UTF-8 BOM 的 Codex 配置。

保留原有工作区、稿件、来源及评分历史。Jev 判断不等于全稿核验，未知与证据不足保持可见。外部 CLI 未提供可靠消息回执的修订仍需在报告页手动检查。

Mac、Windows 与 Python/CLI 复用同一冻结后端 wheel。正式渠道与实际安装状态以发行验收记录为准。
