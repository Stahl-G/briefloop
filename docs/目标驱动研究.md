# 按目标补证

在对话输入框的「研究选项」中，选择「标准」生成，再将「研究方法」设为「按目标补证（试用）」。也可在新建报告要求中选择该研究方法。它目前仍是可选模式，尚未证明全面优于分轮研究。

这个模式从读者的问题出发决定下一步：集中问题可以由主 Agent 直接研究，互不依赖的支线按需交给 Scout。不会因为没有初始材料就强制创建子任务。查询、来源、预算和权限仍使用本次任务已经允许的范围；它不等于无限研究，也不会自动提高模型推理档位。

## 看懂进度

打开报告任务的研究过程，可以看到关键问题：

- **待研究**：尚未提交该问题的覆盖判断。
- **有依据**：主 Agent 提交了回答理由和可回查的原文位置；这不表示已通过独立核查。
- **部分有依据**：部分内容有依据，仍有明确未答部分。
- **尚待回答**：当前没有充分依据，保留未知及其影响。

点击问题下的来源可查看已保存原文。研究轮次记录继续或停止的理由。没有解决所有问题也可以保存工作稿；未知不能被改成没有发生。正式交付仍受既有独立审阅和确定性检查约束。

任务停止与恢复使用原来的任务按钮，保留已收轮的覆盖判断和来源快照。旧版本已经冻结的任务按原契约继续，不要求补填新字段。独立评价仍核对实际稿件和来源，不接受主 Agent 的覆盖自评作为事实证明。

## 与快速模式的区别

联网快速模式只做一轮聚焦检索，先保存初稿，再补依据和评价；它目前不使用研究策略开关，也不自动改写正文。按目标补证属于标准生成流程，可在授权范围内按需要补搜，并沿用最多一次自动修订。

速度与质量需要同时比较：首次保存、完成评价的总用时、关键事实错误、重要问题覆盖和可读性分别记录。快速出稿不等于检查完成，来源较多也不等于研究更完整。
