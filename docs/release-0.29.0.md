# BriefLoop 0.29.0

本版将新建、旧报告导入、下一期复用、明确写作约定和经验反馈串成直接可操作的路径。已合并的 HTML/PDF 导出、来源归档、Codex 历史隔离和状态修复一并发行，具体变化见 CHANGELOG。

写作约定是用户要求，WikiSkill 是需要试写比较的方法候选；两者分开保存。当前合成对照中的一次学习比较持平，候选未采用，不能据此宣称写作质量稳定提高。图文包入库、原图可用和模型实际读图同样是不同状态。

发行复用一个冻结提交和一份共享 wheel，Mac、Windows 与 PyPI 不分别重建后端。正式渠道就绪前不把冻结验收包替换日常安装；各平台实际验收与哈希记录随 release 工件提供。公开下载页和更新索引在发布后同步，用户工作区保留。签名/公证与未测项以实际随包记录为准。

开发验证包括实际浏览器入口、反馈保存和下一期操作，以及服务端作用范围/冻结/失败恢复测试。模型质量试点不代替桌面发行验收；CI 构建的临时包不是正式共享工件。
