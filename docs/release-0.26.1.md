# BriefLoop 0.26.1

本次为 0.26.0 后的修复版本，当前处于发行准备；渠道状态以正式 Release 与验收记录为准。

## 审阅结果不能丢失重大问题

独立审阅中的评分发现与正式核查发现增加关联检查。模型在评分里指出重大问题，却没有把它纳入正式发现时，产品会要求补全审阅，不再接受为完整结果。错误指出需要处理的条目，原始输出保留，普通草稿仍可编辑与下载。

旧版本已经保存的不一致审阅也会在正式交付前被识别；旧记录和原稿不改写，需要补全或重新完成审阅。程序不根据相似措辞猜测关联、不把评分条目自动转换为已核查事实。明确关联的描述可以不同；未提供关联的旧结果只在描述完全相同时兼容。

## 模型目录来自实际服务

BriefLoop Agent 查询已保存提供方的模型 API；Agent CLI 使用宿主目录或本机路由。不再展示内置静态模型建议，新工作区也不自动选具体模型和 High。页面明确目录来源、查询状态和错误；提供方不支持列举模型时可手动输入 ID。保存连接后迟到的旧请求不能覆盖新目录。

已保存的模型选择与运行任务保持原配置。目录能读取不代表已验证推理、工具调用或账户额度；必要的模型协议兼容信息仍单独保留。

## 验证边界

审阅修复使用原始失败结果的副本回放及无需模型派发的离线接纳/交付检查；未改写实验原件，不将结构通过等同事实正确。模型目录已在提供方 API 与网页验证，连接失败也如实显示。各平台安装、导出和更新结果将在冻结构建后单独记录。0.26.0 的原生验收记录不计为本版通过。
