# 证据与结论追溯（开发中）

报告仍可直接编辑和下载。新的证据关联用于说明重要事实、数值、图表和分析推断来自哪里，不把登记动作当成事实已被证明。

## 查看依据

报告页提供“结论与依据”和“当前段落依据”。先点正文中的段落、表格或图片，再打开当前范围的依据；也可查看整份报告已登记的关联。卡片显示主张、正文片段、支持范围、原文摘录和行号／页码／单元格位置，可以继续打开原件。

状态包括语义待审阅、正文变化需复核、锚点失效和来源变化。状态由程序按锚点、正文变化和来源变化计算；没有绑定的内容不会显示为已核验。

## 已保存的关联

- 来源片段：固定来源ID、文本hash、原件hash、具体位置、摘录、抽取方法，以及主体／指标／期间等待核验语义字段。
- 主张：事实、来源观点、计算、推断或建议，及其证据支持范围、前提、推理说明、假设和图表引用。
- 正文位置：固定稿件版本、稳定块ID、唯一正文片段及内容指纹。纯字体变化不改变内容指纹；数值、引用、图片或条件改变会标记需要复核。
- 必答要求：保留原始要求，为目标、显式问题和人工填写项生成稳定ID；作者不能关联不存在的要求ID。

Excel读取保存的原始单元格、公式和缓存值，不执行重新计算。公式缺少缓存时单独标记。PDF无文本或纯图像片段保留视觉检查状态，不能把模型提供的文字转录标成原生文本已核对。

## Agent 接口

沿用 `briefloop tool --workspace ... workspace-action --request ...`：

- `evidence_span`：登记 source_id 与 locator，返回真实 span_id。
- `claim_create`：登记 run_id、主张及其 supports，返回 claim_id。
- `read_run_report`／`read_report`：读取已保存正文版本和 blockId。
- `claim_bind`：把 claim_id 关联到 version_id、block_id 和唯一 quote。
- `evidence_read`：读取当前版本的关联和失效状态。

原始来源、定位和数值检查由程序执行；语义支持、重要主张是否漏绑、计算是否真的执行、冲突及正式交付资格仍需后续独立 Reviewer 与交付流程实现。此文档不是企业验收通过声明。
